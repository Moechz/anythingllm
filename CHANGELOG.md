# Changelog

All notable user-visible changes to the AnythingLLM TOS application package.

## 1.19.0-1 — 2026-11-10

### Added
- First release. AnythingLLM (`mintplexlabs/anythingllm:1.19.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8042 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/anythingllmdocker/`.
